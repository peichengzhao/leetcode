## 状态字典（复制到表格里用）

### 当前状态（主状态，一眼看懂）

| 状态 | 说明 |
|------|------|
| 待投递 | 还没投，在观望或改简历 |
| 已投递 | 已提交，等消息 |
| 测评中 | 在线测评 / 性格测试 / AI 面试 |
| 笔试中 | 已发笔试或等待笔试 |
| 面试中 | 任意轮次面试进行中 |
| 泡池子 | 流程暂停、等排序、等 HC |
| OC / 意向 | 口头 offer 或意向书 |
| 已 Offer | 正式 offer |
| 已挂 | 某环节被淘汰（见挂/拒阶段） |
| 已拒 | 自己放弃 / 拒 offer |
| 无回音 | 投递后长期无反馈 |

### 挂/拒阶段（填「挂在哪里」）

`简历挂` · `测评挂` · `笔试挂` · `一面挂` · `二面挂` · `三面挂` · `HR面挂` · `泡池挂` · `审批挂` · `无 HC` · `自己放弃`

### 投递渠道

`官网` · `内推` · `牛客` · `BOSS` · `猎聘` · `校招群` · `宣讲会` · `猎头`

### 优先级

`高` · `中` · `低`
